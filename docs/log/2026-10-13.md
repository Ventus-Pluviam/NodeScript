### 2026-10-13 —— 悬浮窗拖动跟手 + `▶` 链路径形状收口（用户反馈后）

用户实测反馈两条：① 悬浮窗**不跟手**；② 追问「▶ 链 relPath 双前缀」是否属实。

**① 拖动不跟手 —— 两条真因**（都在 `ui/overlay/`）：
- **手势检测被自己的重组打断**：拖动每帧改状态 → 重喂内容 → 重组，而 `pointerInput`
  的 key 是**每次重组新建**的回调实例 —— 检测协程当场取消重启，手指还没抬手势就断。
  改成 key 恒 `Unit` + 回调经 `rememberUpdatedState` 现取。
- **半速**：窗跟着手指走时本地坐标系被同向抵消，`positionChange()` 逐帧只报真实位移
  的一半。补法是把上一步**真正落位**的位移加回来（用落位量而不是"想挪的量"：
  夹在边缘时窗没动，补 0 才对）。这条链上「落位量」是 `LogWindowController.drag` 的返回值。
- 顺带三件：in-app 兜底窗**也接上拖动**（原写"P0 不做"—— 它是"窗"不是"面板"）；
  位置跨窗存活（关掉再开不弹回原点）；边界夹取（拖不出可视区 —— 拖丢了标题栏就没有
  第二次机会拖回来），两个宿主共用同一份 `x/y` 状态与同一套让位坐标（系统窗 = 可用区，
  in-app = 让完位的内容区；顶边都从状态栏之下起算）。
- **一处 API 选型纠错**：夹取边界原先想用 `getCurrentSizeRange` —— 它给的是**尺寸范围**
  （窗最多多大），窗宽 340dp 在多数设备上正好落在 max 端，于是"max 减窗宽"≈0，
  夹取会把窗**钉死在左上角**。改用 `getCurrentWindowMetrics().bounds`（可用区矩形，
  左/上/右/下四条边一起给 —— 宽度夹取与顶边偏移同源）；API 30 以下退回
  `displayMetrics` + 状态栏资源（近似，如实记在 KDoc 里）。

**② `▶` 链双前缀 —— 属实，是存量 bug**：`ScriptFilesRead` 给的 relPath 是
`files/scripts/` 之下（**首段 = 项目名**，`demo/data/test.js`），而
`AssembledShell.runScriptFile` 把它原样透传给调度器 → 意图日志 → `EngineRunRequest`，
引擎侧 `ScriptPaths.scriptFile` 按**项目内**路径再拼一次项目根 —— 结果是
`files/scripts/demo/demo/data/test.js`，一句 `ERR_FILE_NOT_FOUND`，**编译期毫无迹象**。
2026-10-06 编辑器那条链踩过同一个坑（`ScriptFileOps.resolveInProject` 的 KDoc 里留着记录），
执行链当时没跟上。修法：`:domain` 加 `ScriptPaths.projectInternalOrNull`（判据 = 首段
必须等于 projectId，削不出回 null —— 不静默当项目内路径去跑另一个文件），
`AssembledShell.runScriptFile` 削完再投、削不出当场拒；`MainActivity.runFileWithWindow`
开窗时也换成项目内形状（窗标题与日志绑定与在途表同口径）。两条链上用例钉住
（`AppShellKitTest`：投递进意图日志的 scriptPath 必须只剩项目内那截 + 首段不符要拒）。

**未在本机跑门**（本地禁 gradle）：红绿以 Actions 为准。

### 2026-10-13 —— 执行日志悬浮窗 + 脚本输出按执行持久化 + 暂停执行（用户令）

用户令三条：① 脚本执行时弹**系统级悬浮窗**（TYPE_APPLICATION_OVERLAY，切 App 也能看）
看日志，去「已触发…」toast；② 日志管理「脚本输出」按**每次执行**成列表（标题/图标/
启动时间/大小，运行中显示「运行中」，点行看全文）；③ 悬浮窗四钮（暂停/清空/关闭/全屏，
顺序固定）。文件 ▶ 与任务「立即执行」两处都去 toast、都开窗；定时/后台触发不弹窗但日志照存。

**做了什么**（三提交：`ba63596` 落盘+暂停地基、`a2b3ddd` 悬浮窗+列表、`794997d` 补 stop 误删段）：
- **落盘**：`ConsoleCollector.lineSink` 缝（append 锁外回调、runCatching 不逃逸）+
  `ScriptLogStore`（`filesDir/.ns/script-logs/`，`<runId>.log` JSONL + `index.jsonl`，
  只记 runId≠0）+ `ScriptLogRead`（snapshot last-wins/倒序/size 缺失记 0/running 标记、
  content 截尾 2000）+ `HostSummary.scriptLogIndex/scriptLogContent` + 装配接线
  （`AppShell.assemble` scriptLogs 缝 + `AppShellKit` 建 store）。
- **暂停链**：`ScriptEngine.pause/resume`（缺省 false）→ `SpawnedProcess.pauseExecution/`
  `resumeExecution`（真实现 `kill -STOP/-CONT`，pid null/false 如实）→
  `NodeProcessEngine` 委托 + stop 入口 auto-resume → `RuntimeController.paused` 集
  （pauseRun/resumeRun、watchAnchors 过滤、resume 刷新 startedAt + 心跳 rebase、
  awaitCompletion 暂停冻结 deadline、全部终结路径清集）→ `RunStatus/ActiveRunRow/`
  `ActiveRunState` 带 projectId/scriptPath/paused → `HostSummary.pauseRun/resumeRun`。
  **不加 `EngineStatus.SUSPENDED`**（触点太多）。
- **悬浮窗**：`ui/overlay` 新包（LogWindowState 纯层/LogWindowContent 两宿主共用/
  SystemLogWindowHost 离屏三 owner/控制器/双宿主 + 轮询）+ Glyphs 四字形 +
  MainActivity 接线（in-app 兜底挂 MainShell、系统窗同步效应、开窗期间 400ms 轮询、
  onDestroy 撤窗）+ 两处触发去 toast + 修 `onRunFile` 双 launch 假挂起。
- **列表**：`ScriptOutputList` 重构（在途块+停止链保留，行换按执行，删 dropped/pageFull
  横幅）+ 屏内详情 + `ScriptLogState` + `FileTypeAvatar` 上提共享。
