### 2026-10-29 —— 依赖页第十九批：**卸载/重装动作可辨别（回执改口 + 确认框）**

用户真机反馈链收官的两件（第十七批第 41 条）：回执话术与动作手感。背景：用户反复报告
「卸载 axios 后列表不刷新、日志却是 added N packages（安装签名）」。排查走查了 UI 接线
（卸载 → `npm uninstall <name>` 命令构造与宿主分发逐字正确）、宿主执行链（`enqueueHeavy`
协程内联、`prepareWorkDir` 逐字复刻两代 npm 行为）—— 宿主卸载路径的输出签名与用户日志
不符（卸载在空 workDir 里是 `up to date`、锁条目真删，`added N` 是 install 方向的语言），
「added 1 package in 2s」这类单补输出在宿主封装（workDir 每次从零起）下物理不可达。
无法在设备上复现的归复现不了，能修的观感缺陷（回执骗人 + 误触无感）先修。

**第 41 条：回执改完成句式**（`NpmInstallOps.noticeForPanel`）。`runPanelCommand` 等到

"刚提交、还在装"，正是「卸载没生效」观感的一半来源。改口：动作名 + 对象 + 结果
（「已卸载 esbuild：清单已更新」/「已安装 axios@1.7.9：清单已更新」，对象取命令里
第一个非旗标 token），不再出现「在跑」。
