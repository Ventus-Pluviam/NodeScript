### 2026-10-05 —— 批 48：设置页「权限」入口进子页 + 补列使用情况访问权限

- **驱动**：用户一条——「设置弄一个名字叫权限的列表，把其他的权限模块都放进去」。
- **当场问定两条**（AskUserQuestion）：「其他」= **还要补未列出的权限**（清单在册但没进能力列表的，如实补进去 —— 实指 manifest 已声明的 `PACKAGE_USAGE_STATS`，服务 `auto.app.currentPackage`，八项 `Capability` 里没有它）；形态 = **顶层入口进二级页**（TG 主设置页「Privacy and Security」的形：设置顶层给一条命名的「权限」列表入口，点进去是二级页列全部权限模块）。
- **逐条落点**：
  1. **新能力 `USAGE_ACCESS`（使用情况访问权限）端到端**：`:domain` `Permission.kt` 的 `Capability` 枚举追加第九项（枚举序 = 设置页行序）；`PermissionCenter.guideText` 补第九条（「设置 → 应用 → 特殊访问权限 → 使用情况访问权限」允许 AutoScript；未允许时 `auto.app.currentPackage` 如实返回 null）；`:app` `CapabilityProbes.usageAccessGranted()` —— `AppOpsManager.checkOpNoThrow(OPSTR_GET_USAGE_STATS, myUid, pkg) == MODE_ALLOWED` 问 AppOps 而**不是**拉 `UsageStatsManager` 列表（拉列表会把「空列表」与「没权限」混成同一个 false）；reader 三态 = GRANTED / DENIED（**无降级路径** —— 没权限时 currentPackage 就是 null，没有受限但仍可用的中间态），出厂 DENIED 集合断言 3→4；`GrantPage.USAGE_ACCESS` + `pageFor`/`specFor` = `Settings.ACTION_USAGE_ACCESS_SETTINGS`（常驻列表页，**不带**定位本应用的 extra —— 系统会忽略它，测试里显式断言无 extra）。
  2. **设置页改两层**（`SettingsScreen.kt`）：顶页 = 头部标识区（批 47 那张脸不动）+ **一条「权限」入口**（`SettingsCellRow` 新增副标题档：13sp、最小高 50→60dp，TG `SettingCell` 的 twoLines 档；副标题挂读态 `Status.of` —— 尚未读取 / 读失败原文 / N 项）+ 降级定时任务段（§8.6 的账，留在顶页）；点入口进子页 —— `rememberSaveable` + `BackHandler(enabled = permissionsOpen)` 系统返回先关子页（本屏随页签切走即退出组合，不会替别的页签拦返回键，与 ProjectScreen 子态同一口径）；顶栏随层互换：顶页 = `title = null` + 右上 `⋮`，子页 = 「‹ 返回 + 权限」。**子页** = 权限九行同卡无分隔线、行尾三态值、可授权整行可点；没读到 / 读失败卡内如实一句，**不铺空卡**。读态从头部副标题位**挪到入口副标题位**（它描述的就是那张清单本身，头部只剩图标 + `NodeScript`）。
  3. **视觉**：新字形 `GlyphKind.CHART`（三柱状图，不画坐标轴 —— 24dp 里轴线会糊成表格）；入口行 SHIELD + 靛蓝色对；使用情况访问行粉色对（`iconColors`/`glyph` 两处穷尽 `when` 补齐）。
- **测试**：`AndroidSystemStateReaderTest`（FakeProbes 补 `usageAccessGranted` 探针 + 新增「没开是 DENIED —— currentPackage 没有降级路径」用例（双态 + 尾 `Unit`）+ 出厂 DENIED 集合 3→4）；`AndroidGrantLauncherTest` 去向表补 `USAGE_ACCESS`；`AndroidPermissionGatesTest` 补 `specFor` 字面量 + 无 package extra 断言；`guideText` / `label` / `pageFor` 的穷尽遍历测试自动覆盖第九项（枚举驱动，不用改断言）。
- **诚实边界**：`currentPackage` 的宿主实现尚未接线（wire 方法名在位、`:app` 无 launcher 实现）—— 本批只补**权限清单与三态读数**这一面：探针如实按 AppOps 回答，不假装该功能已通。批 47 撤下的是 `guide` 的**渲染**，字段与透传照旧，本批第九条文案同源进 `guideText`。
- **门**：`:domain:test`（71 绿）+ `:app-service:permission-center:test`（11 绿）+ `:ui:testDebugUnitTest`（102 绿）+ `:app:testDebugUnitTest`（**221** 绿，含新增 1 例）+ 全模块 `lintDebug` + `:app:assembleDebug`，全绿零跳过零警告升级。用户指定通过 GitHub Actions 编译交付，设备交互测试由用户完成，本批不使用 ADB。
