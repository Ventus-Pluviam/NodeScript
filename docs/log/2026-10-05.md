### 2026-10-05 —— 批 43：搜索框几何再纠偏（补第二层内缩）+ 首行间距 + 首页搜索框对齐

- **驱动**：用户四条——TG 的搜索框比本仓还短一点；任务界面搜索框离第一个列表距离不够（要和 TG 一样）；搜索框边缘样式要和 TG 一样；首页搜索框的放大镜图标与长宽也一起改。
- **三处口径当场问定**：药丸几何用 **TG 原值 40dp**（宽 = 屏宽 −24dp、距屏边 12dp）；搜索框到首卡间距 **8dp 档**（落到 12dp 净留白）；首页搜索框按 **灰框 + 新几何 + 新图标**（TG `DialogsActivity` 档，不是白药丸）。
- **逐条落点**：
  1. **药丸几何纠偏（批 42 只算了一层内缩）**：批 42 把 `setSectionBackground()` 的 `setPadding(dp(3),…)` 当成唯一内缩层，漏了药丸背景本身 `createRoundRectDrawableShadowed(dp(20), …)` = **`InsetDrawable(defaultDrawable, dp(3), dp(3), dp(3), dp(3))`** —— 两层各让 3dp。真实可见药丸 = 52dp 槽位 − 槽位外 6×2 − padding 3×2 − InsetDrawable 3×2 = **屏宽 −24dp、高 40dp**、距屏边 12dp。`TaskCenterScreen.SearchField` 槽位 padding 9→**12dp**、药丸 46→**40dp**。
  2. **搜索框下空隙**：列表 `contentPadding.top` 54→**52dp**（药丸底 40 + 12dp 净留白，TG 空态药丸底到首行同口径），首卡不再贴着药丸。
  3. **边缘样式**：圆角 20dp 落在 40dp 高上 = **两端全圆**（半圆帽；46dp 高时只是四角圆角的方片）；投影维持 `setShadowLayer(2dp, 0, 0.33dp, 0x11000000)` 的 2dp elevation 近似。
  4. **首页（`ProjectScreen`）搜索框对齐 TG `DialogsActivity` 档**：`GlyphKind.SEARCH`→**`SEARCH_FIELD`**（`outline_search_1_24` 实测粗环短柄），槽位 padding 7/4→**12/6**、高 48→**40dp**（宽随之为 屏宽 −24dp）；底色保持 `fieldBackground`（白底压 5% 黑的灰、无投影 —— 与任务栏那颗白药丸不是一个键，TG 源码本就是两条 `createRoundRectDrawable*` 分支）。
- **门**：`:ui:testDebugUnitTest`（97 绿）+ `:ui:lintDebug` 绿 + `:app:compileDebugKotlin`/`:app:testDebugUnitTest`（220 绿）+ 文档链接门 393 条全过。本机同源直跑。

### 2026-10-05 —— 批 40：任务栏重做（TG 联系人页复刻）

- **范围**：`:ui`（TaskCenterScreen 全量重写 + Glyphs/Theme/TaskCenterState 增量）+ `:app`（MainActivity 接线）；无契约变更（`HostSummary` 读口原样）。
- **驱动**：用户指令——任务界面全部按 TG 联系人页（ContactsActivity）的组件与样式复刻；设计分歧三问三答拍板：任务列表组**取消、换成「运行中的任务」**（数据源 = 控制台 `activeRuns`）；运行中 + 定时任务**同卡**（一张白色圆角卡片包两组，组间留白）；不做任务日志；「立即执行」放**行尾**（未执行 = 实心播放三角、该任务挂起中 = 转圈的开口弧）；登记表单入口 = **右下角 FAB**（表单弹底部面板）；**点行 = 底部操作面板**（立即执行/取消任务/复制脚本路径）。
- **逐字几何**（TG 源码实测）：
  - 屏底 = `key_windowBackgroundGray`（`ThemeColors.surfaceMuted`）；白卡 = `setSections(dp(12), dp(16), false)` 的读法（水平 12dp、圆角 16dp、无投影——`SharedConfig.shadowsInSections` 缺省 false、首行顶 4dp）。
  - 分组头 = `GraySectionCell`：32dp 条、14sp Medium、`graySection` 底 + `graySectionText` 字（**Theme.kt 新增两 token**：浅 0xFFF6F6F6/0xFF84878A、深 0xFF0B0B0C/0xFF838384），整条可点 = 展开/收起。
  - 任务行 = `UserCell` 的 **call 样式**（联系人页实际用的那档，`setCallCellStyle(58)`：行高 56dp、头像 44dp 圆、名字 15sp Medium、次行 13sp、分隔线缩进 68dp）；头像 = 脚本类型徽标（FileTypeAvatar 的 44dp 版）。
  - 搜索栏 = `FragmentSearchField`：52dp 槽位、水平 6dp、内缩 3dp、圆角 20dp **白色**药丸 + 2dp elevation 投影（`createRoundRectDrawableShadowed`）、提示词「搜索任务」50%、图标 60%、文字 15sp。**与项目页搜索框不是一个底色键**（那页白底压 5% 黑，这页灰底上是白药丸）。
  - 排序切换钮 = `msg_contacts_name`/`msg_contacts_time` 两态（**Glyphs.kt 新增 SORT_NAME/SORT_TIME/PLAY 三字形**；webp 实测几何：三条圆头横杠 y≈0.23/0.45/0.67，尾缀 = 切过去的那一档——按名称时显示时钟）。**图标语义与 TG 同款**：`sortItem.setIcon(sortByName ? msg_contacts_time : msg_contacts_name)`。
- **诚实边界一条不松**：副标题仍 `Status.count` 三态；卡内空行区分「尚未读取/读失败原文/读到了没有」；opError 不清清单；恢复账/未结算执行**不再铺列表但各留一行**如实提示（藏事实与铺一屏日志之间取「说一句」）；取消仍有确认框；挂起中操作按钮停用。
- **状态层新增（纯 JVM，有测试）**：`TaskSort` 枚举 + `sortedTasks()`（按名称=字典序；按时间=下一跳早的在先、null 排最后、同刻按名称收尾）+ `TaskRowState.matches()`（名称/路径含词）；`TaskCenterState` 新增 `opTargetTaskId`（挂起中的立即执行落在哪条——那行的播放钮才转圈）与 `TaskRowState.nextFireAtMillis`（排序键原样投影）。
- **MainActivity 接线**：`TaskCenterScreen` 增收 `console: ConsoleState`（运行列表 + 停止三态）与 `onStopRun`；`runTaskNowOp` 先落 `opTargetTaskId` 再走 `performTaskOp`（finally 收回）；**切到任务页签两侧都现取**（`reloadTasks() + reloadConsole()`——运行中那组的数据在控制台账上）。
